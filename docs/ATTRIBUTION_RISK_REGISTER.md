# Constrained attribution risks

| Risk | Treatment | Residual limitation |
|---|---|---|
| Common limits mistaken for common realised risk | Enforce identical private rectangles; report actual innovation exposure and downside separately. | Equal permitted exposure does not imply equal variance, activity or drawdown. |
| Parameter/selection effects labelled reset value | Equal recorded tuning budget, shared package selected before test, explicit package-transfer diagnostics. | Sparse candidate grid and selected-package uncertainty remain. |
| Post-treatment risk matching | No path filtering, rescaling or seed exclusions based on exposure/fills. | This estimates a constrained policy contrast, not a risk-normalised causal effect. |
| Unidentified continuation or fill model | Keep original scalar approximation fixed; no R3 or new fitted kernel promotion. | Failure/success concerns this approximation and declared generators, not all possible reset policies. |
| Pseudoreplication and adaptive testing | Average opponent repetitions within paths; stratify scenario bootstrap; one fixed primary. | Approximate bootstrap/normal power, synthetic PRNG independence assumptions. |
| Pilot variance fails to transfer | Predetermined floor/cap, held-out final opponent structures, explicit cap flag. | Planned power is not guaranteed even when cap does not bind. |
| Incorrect quote/pending capacity | All-subset private-box validation, full traces and adversarial tests. | Supported boundary schedule only; no arbitrary network certificate. |
| Correct ledger mistaken for market realism | Independent full ledger and terminal replay. | Prices/competitors/customer laws are synthetic and exchange liquidity is simplified. |
| Newness inferred from terminology or volume of code | Refresh nearest primary comparisons and keep novelty inconclusive. | Independent expert review and complete literature search remain external to this study. |
